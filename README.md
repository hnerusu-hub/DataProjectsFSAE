IWDATA - This is the in-person workshop data project we did with the four various graphs. 


THDATAReal - This script visualizes data from the .parquet file, showing speed, torque, battery performance, GPS path, and wheel speed comparisons. It helps analyze the car performance, power efficiency, and track behaviors using Polars and Matplotlib. 

THDATAChallenge - This helps visualize the vehicle's drag coefficient multiplied by cross-sectional area (CdA) using telemetry data from a .parquet file. It filters valid data, computes motor power and speed, estimates CdA values, and plots them against speed to analyze aerodynamic performance.
